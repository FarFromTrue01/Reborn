# Sahne görselleri (CG)

Buraya sahne görsellerini koy: `<sahne>.png`

- `title` — başlık ekranı arka planı
- `void` — beyaz boşluk
- `battlefield` — prologdaki uzak savaş alanı
- `forest_wake` — ormanda uyanış
- `village_view` — ağaçların arasından köy ve uzaktaki şehir

Önerilen boyut: 1920×1080 veya 3:2 oran (ör. 1800×1200). Dosya yoksa oyun kodla çizilmiş bir sahne gösterir.
